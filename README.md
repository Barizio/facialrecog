
# Facial Recognition Using Machine Learning Techniques

## Project Overview
This project implements a Python-based facial recognition system that identifies or verifies individuals in real time using machine learning techniques. The system processes live video input from a webcam and compares detected faces against a stored dataset to either identify individuals or mark them as "Unknown."

## Features
- Detects faces in real-time from a webcam feed.
- Matches detected faces against a pre-encoded dataset.
- Records the annotated video output.

## How to Run

### 1. Prepare the Dataset
1. Create a folder named `dataset/`.
2. Inside `dataset/`, create subfolders for each person you want the system to recognize.
   - Name the subfolders with the corresponding person's name (e.g., `Adebare`, `John`, `Mary`).
3. Add multiple images of each person to their respective subfolder.

Example structure:
```
dataset/
├── Adebare/
│   ├── adebare1.jpg
│   ├── adebare2.jpg
│   ├── adebare3.jpg
├── John/
│   ├── john1.jpg
│   ├── john2.jpg
│   ├── john3.jpg
├── Mary/
│   ├── mary1.jpg
│   ├── mary2.jpg
│   ├── mary3.jpg
```

### 2. Encode Faces
Run the `encode_faces.py` script to process the dataset and generate the `face_encodings.pkl` file:
```bash
python encode_faces.py
```

### 3. Run Real-Time Recognition
Once the face encodings are created, run the real-time face recognition script:
```bash
python real_time_face_recognition.py
```
- The system will open a webcam feed and display the recognized faces in real-time.
- The output will be saved as `output.avi` in the project directory.

---

## Code Explanation

### 1. `encode_faces.py`
- Scans the `dataset/` folder.
- Encodes each face using a pre-trained model.
- Saves the encodings and corresponding names to `face_encodings.pkl`.

### 2. `real_time_face_recognition.py`
- Loads face encodings from `face_encodings.pkl`.
- Captures live video feed from the webcam.
- Detects faces in real-time, matches them to the encodings, and annotates the video.
- Saves the annotated video as `output.avi`.
